# 🎙️ App de Voz - Conversor de Texto em Áudio

Um aplicativo Web interativo desenvolvido para transformar texto em áudio em tempo real, utilizando as vozes autorizadas e instaladas no próprio dispositivo do utilizador.

## 🚀 Funcionalidades

* 📝 **Texto para Fala:** Converte qualquer texto digitado em leitura audível.
* 🗣️ **Seleção de Voz Autorizada:** Detecta e lista automaticamente as vozes disponíveis no dispositivo (Microsoft, Google, Apple, etc.), permitindo a escolha da voz preferida.
* ⏸️ **Controles de Áudio:** Opções para Iniciar, Pausar e Parar a reprodução a qualquer momento.
* 🔒 **Privacidade Total:** Processamento 100% local no navegador do utilizador, sem envio de dados para servidores externos.

## 🛠️ Tecnologias Utilizadas

* **HTML5**
* **CSS3**
* **JavaScript** (Web Speech API - `SpeechSynthesis`)
